Jetstream v2 · sealed archive + live

Replays sealed .jss archive segments and merges them into the live tail as one ordered, duplicate-free stream via the dedicated connectJetstreamV2 binding. A live-only tail needs no key; bounded replay (afterSeq/beforeSeq/snapshot) reads the authenticated archive and needs an access key.

The archive key is held only in this tab's memory for the run — it is never written to storage or the URL, and the field is cleared once the stream starts. Do not paste a long-lived key into a page you do not control.
